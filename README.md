# QuorumLab

Учебный инженерный проект: распределённое key-value хранилище на Java 21 с собственной реализацией Raft, дисковым журналом и детерминированной лабораторией отказов.

Главный результат — проверяемая корректность в заданной модели сбоев. Проект не предназначен для критичных данных или публичного production-развёртывания.

**Статус на 7 ноября 2026:** подготовлен стартовый пакет документации M0 и правила Git. Пользователь подтвердил Java 21/Git и расширения VS Code, создал [GitHub-репозиторий](https://github.com/yergaliuly/QuorumLab). Локальная ветка — main, origin и автор yergaliuly настроены. Кода приложения, сборки и тестовых результатов продукта пока нет. Разработку и проверки выполняет ассистент с объяснениями, push выполняет пользователь.

## Границы первой версии

Одна Raft-группа из трёх постоянных voting nodes; quorum — два узла. Операции PUT, GET, DELETE и CAS; собственные WAL, HardState и snapshots; восстановление и проверка историй операций. Ядро не зависит от сети, файловой системы, системного времени и Spring.

Последовательность: фундамент → storage → выборы → репликация → KV и клиент → реальный кластер → snapshots → расширенная симуляция → глубокая проверка → dashboard и демонстрация. Минимальный симулятор развивается с первых этапов.

Команды запуска появятся после реализации и проверки соответствующих этапов. Планируемые возможности не являются уже работающими гарантиями.
