# QuorumLab

Учебный инженерный проект: распределённое key-value хранилище на Java 21 с собственной реализацией Raft, дисковым журналом и детерминированной лабораторией отказов.

Главный результат — проверяемая корректность в заданной модели сбоев. Проект не предназначен для критичных данных или публичного production-развёртывания.

**Статус на 9 ноября 2026:** сборочный PR #1 принят, CI на Ubuntu/Windows прошёл. Подготовлен следующий срез M0: начальные контракты ядра и адаптеров, детерминированный scheduler и 44 тестовых случая; полная сборка прошла на Windows/WSL. CI нового кода ожидает пользовательского push в [репозиторий](https://github.com/yergaliuly/QuorumLab). Алгоритм Raft и хранилище ещё не реализованы, весь M0 не завершён.

## Сборка

Нужен JDK 21; первый запуск загружает Gradle и зависимости. В PowerShell из корня проекта:

```powershell
.\gradlew.bat clean test build
```

На Linux: `./gradlew clean test build`. Глобальная установка Gradle не нужна. Тесты core и scheduler выполняются обычным build; остальные восемь модулей пока показывают `NO-SOURCE`. Подробности — в [руководстве по сборке](docs/BUILD.md).

## Границы первой версии

Одна Raft-группа из трёх постоянных voting nodes; quorum — два узла. Операции PUT, GET, DELETE и CAS; собственные WAL, HardState и snapshots; восстановление и проверка историй операций. Ядро не зависит от сети, файловой системы, системного времени и Spring.

Последовательность: фундамент → storage → выборы → репликация → KV и клиент → реальный кластер → snapshots → расширенная симуляция → глубокая проверка → dashboard и демонстрация. Минимальный симулятор развивается с первых этапов.

Команды запуска кластера появятся после реализации соответствующих этапов. Планируемые возможности не являются уже работающими гарантиями.
