# M1 WAL Codec Implementation Plan

**Goal:** реализовать QL-005: строгий versioned codec четырёх операций WAL с CRC32C и тестами повреждений/границ.

**Architecture:** пакет quorum-storage/wal содержит immutable records, codec и типизированную ошибку. Storage использует NodeId из core. Чтение/запись файлов, durability и recovery не входят в этот срез; источник данных codec — ByteBuffer.

**Tech Stack:** существующие Java 21/Gradle/JUnit; стандартные ByteBuffer, UTF-8 и CRC32C. Новых внешних зависимостей нет.

**Spec:** [дизайн формата](../specs/2026-11-15-wal-codec-design.md), [ТЗ §6](../../TECHNICAL_SPECIFICATION.md). Направление собственного WAL уже задано проектом и текущим запросом; детали формата записаны как решения реализации.

## Constraints / review focus

- Один исполнитель, один checkout, ветка `feat/m1-wal-codec`, push делает пользователь.
- Header 11 bytes, overhead 15 bytes, payload <=1 MiB; CRC покрывает header и payload.
- Decode не изменяет position при incomplete/error; не обрезает файл и не решает tail policy.
- Строгий UTF-8; immutable command bytes; никакого использования enum ordinal как wire ID.
- Проверять необычные buffers, переполнения длины, валидный CRC на неверном payload и независимый golden format, не только roundtrip.
