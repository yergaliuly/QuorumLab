# M0 Build Implementation Plan

> **For agentic workers:** use superpowers:executing-plans for this small, approved build slice; preserve the user's single-agent workflow and leave push to the user.

**Goal:** воспроизводимая сборка десяти Java-модулей на Java 21 с JUnit 5 и CI для Windows/Linux.

**Architecture:** общие Java/test-настройки находятся в корневом Gradle Kotlin DSL; settings перечисляет модули. Пока нет алгоритма и межмодульных зависимостей. Dashboard и proto представлены только поясняющими README, без frontend/gRPC toolchain.

**Tech Stack:** Gradle 9.9.0, Java 21, JUnit BOM/Jupiter 5.14.4, GitHub Actions.

**Spec:** [ТЗ](../../TECHNICAL_SPECIFICATION.md), разделы 4 и 9; пользователь прямо подтвердил этот срез в чате. Это не весь M0.

## Global Constraints

- Работать в текущей ветке `feat/m0-foundation`, без нового worktree и без префикса codex.
- Push делает пользователь; computer use запрещён. Не устанавливать глобальный Gradle.
- JUnit только в test configurations; runtime/compile classpath ядра должен оставаться без зависимостей.
- Не создавать Raft, storage, scheduler или постоянные фиктивные тесты ради зелёного отчёта.
- Версии Gradle/JUnit взяты из официальных release/Maven metadata; Actions закрепить полными SHA.

## Review Focus

1. Wrapper на Windows и Linux: окончания строк, executable bit, официальный JAR и distribution SHA-256.
2. JUnit действительно обнаруживает тест и делает сборку красной при assertion failure.
3. Java 21 используется для компиляции и тестового процесса, включая модуль с реальным временным исходником.
4. Сборка из корня охватывает все десять модулей; core не получает JUnit в runtime.
5. CI описан корректно, но его реальный GitHub run до пользовательского push не заявляется выполненным.

## Execution notes

Работа выполняется inline. Служебные прогоны и временный probe — в игнорируемом `tmp/`; постоянный результат и свидетельства — в BUILD/PROJECT_STATE. Для конфигурационного среза используем фактические build/probe проверки, не добавляем искусственную продуктовую функцию ради TDD.

Task 1 complete: Windows build, ожидаемый RED и GREEN JUnit, пустой core runtimeClasspath, Linux build/probe и финальный обычный build. Task 2 complete: actionlint и фактические inputs закреплённых Actions проверены; документация и staged review готовы. Результат фиксируется локальным коммитом `build: add Java 21 Gradle foundation and CI`; push остаётся пользователю.

Final self-review: изменений за пределами согласованного build slice нет; generated Wrapper проверен по официальному checksum, Linux script синтаксически корректен и исполняемый в Git, все десять модулей участвуют в root build. Блокирующих замечаний нет. 21 локальная ссылка корректна, в индексе нет tmp/build output. Реальный CI и продуктовые тесты явно отмечены как ещё не выполненные.

Ruling: сохраняем текущий checkout и выполняем самостоятельный review без дополнительного агента — это предпочтения пользователя и небольшой конфигурационный срез. Реальный GitHub runner до push непроверен; Linux WSL build не заменяет будущие storage crash/fsync tests.
